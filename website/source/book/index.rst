The CppVerify Book
==================

A guided introduction to formal verification and to writing verified C++ with CppVerify.

**Part I** develops the core ideas—specifications, program logic, loops, memory, and automated
proof. **Part II** applies them in C++: contracts, the verifier, and the compiler workflow.
